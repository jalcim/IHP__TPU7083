# TPU7083-main

Source files of the TPU7083 chip.

- rtl/ : Verilog RTL of the design (25 files).
- The other subfolders come from the template and are empty for now.

Release views are in release/v.1.0.0/ :
- gds/TPU7083.gds.gz : layout.
- netlist/ : gate netlist (TPU7083.nl.v), powered netlist (TPU7083.pnl.v), SPICE netlist (TPU7083.spice).
- doc/drc/ : precheck report.

The datasheet and specification are in doc/.
Macro dependencies are in dependencies/.
